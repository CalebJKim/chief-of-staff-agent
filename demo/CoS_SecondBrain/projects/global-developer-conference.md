# Global Developer Conference

This project prepares developer sessions, demos, speakers, and follow-up material. The audience should be able to move from understanding an idea to trying an example and knowing where to get help.

## Learning package under discussion
The proposed package combines an introductory workshop, guided integration example, troubleshooting clinic, and support handoff. Each part has a different job:
- The workshop explains the problem and prerequisites.
- The example shows the steps and boundaries.
- The clinic explains how to diagnose setup, access, and source problems.
- The handoff points to maintained resources and support.

[[developer-ecosystem-expansion]] holds the broader plan.

## What needs preparation
An environment checklist, facilitator notes, participant guide, annotated example, and troubleshooting worksheet. State the configuration each assumes and how corrections will be published.

The program still needs decisions about the audience's experience level, hands-on participation, and support after the session. Speakers, dates, publication approval, and session selection are not established here.

## Presentation alternatives
Prepare a recording or screenshot walkthrough if appropriate, with its limitations explained. It can teach the steps, but it is not proof that a live configuration works.

A successful keynote moment is not enough if attendees cannot find or use the supporting material. Check the experience after the event as well as on stage.

Partner examples can be reviewed through [[partner-certification]]. The conference program and [[ifa-demo-slate|IFA demo list]] require separate selections. Confirm owners and next decisions through [[weekly-leadership-staff]] and record commitments in [[decision-log]].
