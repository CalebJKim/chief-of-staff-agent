Chief of Staff Demo

Portable Windows ARM64 package for the NVIDIA RTX Spark N1X.

Install

  1. Double-click Install Chief of Staff Demo.
  2. Enter the credential-package passphrase when prompted. Input is masked.
  3. Wait while the model, llama.cpp, Hermes, Google credentials, and reference workspace are prepared.
  4. Use the desktop shortcut Start Chief of Staff Demo.

Requirements

  • Windows 11 ARM64 on an NVIDIA RTX Spark N1X
  • 64 GB unified memory with the 16 GB GPU / 48 GB CPU carveout
  • At least 30 GiB free on the internal SSD
  • Internet access for Google Workspace and the pinned Hermes bootstrap

Normal operation

After installation, the USB is not required. Start, reset, diagnostics, and repair shortcuts are provided. The local model listens only on 127.0.0.1:8080.

When finished

Run Finalize and Remove Demo from this folder. It can remove the seeded Google workspace, revokes the copied OAuth token, removes the local installation, and then deletes this single USB folder.

Important: Keep this drive and its credential-package passphrase under your control. The encrypted package contains a Google refresh token for the demo account.
